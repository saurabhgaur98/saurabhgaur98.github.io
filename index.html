About Me & Core Expertise

Practical engineering grounded in modern Android architecture and real-world product delivery.

Building Production-Ready Mobile Applications

I am an Android Developer with 1.5+ years of professional experience currently working at Appsinvo Pvt. Ltd., after starting out as an Android Developer Intern at Uptoskills. My day-to-day work focuses on developing and maintaining native Android applications using Kotlin and Java, crafting responsive user interfaces across both Jetpack Compose and XML layouts.

I have contributed to applications spanning ride booking, healthcare, pharmacy medicine ordering, doctor consultations, e-commerce print and stationery workflows, device-to-device data transfer, and travel booking, alongside personal projects such as a weather app and a notes app. I structure applications around MVVM and Clean Architecture so features remain modular, maintainable, and resilient across releases.

My responsibilities cover REST API integration with Retrofit, offline persistence with Room Database, real-time event handling with Socket.IO and Agora RTC/RTM, location tracking with Google Maps SDK, push notifications via Firebase Cloud Messaging, payment gateway integration, performance debugging, and daily collaboration with backend developers, designers, and QA teams.
